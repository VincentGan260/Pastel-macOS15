# 26.7

## 简体中文

- 搜索支持区分 iPhone、iPad 和 Apple Vision Pro App。
- 下载页可手动输入 App ID 获取最新版。
- 支持拷贝 App ID 和版本 ID。

## 繁體中文

- 搜尋支援區分 iPhone、iPad 和 Apple Vision Pro App。
- 下載頁可手動輸入 App ID 取得最新版。
- 支援拷貝 App ID 和版本 ID。

## English

- Search now separates iPhone, iPad, and Apple Vision Pro apps.
- Fetch the latest version by entering an App ID on the Downloads page.
- Added copying of App IDs and version IDs.

## 日本語

- iPhone、iPad、Apple Vision Pro の App を分けて検索できます。
- ダウンロード画面で App ID を入力し、最新版を取得できます。
- App ID とバージョン ID をコピーできます。

## 한국어

- iPhone, iPad, Apple Vision Pro 앱을 구분해 검색할 수 있습니다.
- 다운로드 화면에서 App ID를 입력해 최신 버전을 받을 수 있습니다.
- App ID와 버전 ID 복사를 지원합니다.

## ภาษาไทย

- แยกค้นหาแอปสำหรับ iPhone, iPad และ Apple Vision Pro ได้
- รับเวอร์ชันล่าสุดด้วยการกรอก App ID ในหน้าดาวน์โหลด
- รองรับการคัดลอก App ID และ Version ID
