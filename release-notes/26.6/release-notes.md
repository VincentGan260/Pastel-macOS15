# 26.6

## 简体中文

- 减少重复的双重认证和钥匙串确认。
- 手动下载支持自定义 App ID 和“不再更新”选项。
- 修复部分多语言界面显示问题。

## 繁體中文

- 減少重複的雙重認證和鑰匙圈確認。
- 手動下載支援自訂 App ID 和「不再更新」選項。
- 修復部分多語言介面顯示問題。

## English

- Reduced repeated two-factor authentication and Keychain prompts.
- Manual downloads now support custom App IDs and the “No Updates” option.
- Fixed display issues in some languages.

## 日本語

- 2 ファクタ認証とキーチェーンの確認回数を減らしました。
- 手動ダウンロードで App ID の指定と「アップデートしない」に対応しました。
- 一部の言語での表示を修正しました。

## 한국어

- 반복되는 2단계 인증과 키체인 확인을 줄였습니다.
- 수동 다운로드에서 App ID 지정과 “더 이상 업데이트 안 함”을 지원합니다.
- 일부 언어의 화면 표시 문제를 수정했습니다.

## ภาษาไทย

- ลดการขอยืนยันตัวตนแบบสองปัจจัยและการยืนยันพวงกุญแจซ้ำ
- การดาวน์โหลดด้วยตนเองรองรับ App ID ที่กำหนดเองและตัวเลือก “ไม่อัปเดตอีก”
- แก้ไขการแสดงผลในบางภาษา
