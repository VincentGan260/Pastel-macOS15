# 26.5.2

## 简体中文

- 新增“不再更新”下载选项。
- 下载列表可查看版本 ID 和更新状态。

## 繁體中文

- 新增「不再更新」下載選項。
- 下載列表可查看版本 ID 和更新狀態。

## English

- Added a “No Updates” download option.
- The download list now shows version IDs and update status.

## 日本語

- ダウンロード時に「アップデートしない」を選択できます。
- ダウンロード一覧にバージョン ID と更新状態を表示します。

## 한국어

- 다운로드에 “더 이상 업데이트 안 함” 옵션을 추가했습니다.
- 다운로드 목록에 버전 ID와 업데이트 상태를 표시합니다.

## ภาษาไทย

- เพิ่มตัวเลือก “ไม่อัปเดตอีก” ขณะดาวน์โหลด
- แสดง Version ID และสถานะการอัปเดตในรายการดาวน์โหลด
